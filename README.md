# Project Name
الذكريات (Alzikrayat)

# A Simple Description
تطبيق ويب لمشاركة الصور والتعليق عليها بين المستخدمين، مبني بمعمارية 
MVC و3-Tier 
من الصفر بدون استخدام أي فريم وورك 
 جاهز. يتيح للمستخدمين إنشاء حساب، رفع الصور، ومشاركتها مع الآخرين، مع حماية كل صورة بحيث لا يستطيع حذفها إلا صاحبها

# Technologies
- PHP (بدون أي framework)
- MySQL
- HTML5, CSS3, JavaScript
- Bootstrap 5
- Apache (XAMPP)

# How to Run
1. تثبيت XAMPP وتشغيل Apache و MySQL
2. استيراد قاعدة البيانات من خلال phpMyAdmin
3. وضع مجلد المشروع داخل htdocs
4. فتح الرابط: `http://localhost/alzikrayat/public/photos`
